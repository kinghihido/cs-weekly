# Week 02 挑战 · 给自己做一次密码体检

这周不考算法，考「亲眼看一次自己是怎么被保护的（或者没被保护的）」。
三级任选，**做完任意一个都算赢**，不需要写超过 10 行代码。

⚠️ 唯一的硬规矩：**任何地方都不要写出你的真实密码。**
写下「结构」（几位、什么类型、用在几类网站）就够了。指纹是安全的（反推不出密码），密码不行。

讲义在 [README.md](README.md)，可交互版在仓库根目录的 [`index.html`](../index.html)。

---

## Lv 1 · 观察（15 分钟 · 零代码）

**目标**：知道自己现在站在多危险的地方。

- [ ] 打开 [haveibeenpwned.com](https://haveibeenpwned.com/)，输入你的**邮箱**，看它出现在几次泄露里、分别是哪些网站。
- [ ] 再进「Passwords」页，输入一个你**已经不用了**的旧密码，看它是否在公开泄露库里。
      （这个页面用 k-匿名：只上传指纹的前 5 位，对方不知道你的完整指纹 —— 这正是讲义第 02 节讲的原理）
- [ ] 数一数：你有几个重要账号（邮箱、微信、银行、学校系统）？其中几个**用的是同一个密码**？
- [ ] 用三句话写结论，例如：「我有 6 个重要账号，其中 3 个密码相同；我的邮箱在 2 次泄露里出现过。」

**你会学到**：风险不来自「黑客盯上你」，来自「同一个密码用在了太多地方」。

## Lv 2 · 动手（20 分钟 · 代码 10 行）

**目标**：亲手验证「加盐」和「雪崩」不是背下来的概念，是你电脑上跑出来的事实。

- [ ] 把 [salt_demo.py](salt_demo.py) 存到本地，运行 `python salt_demo.py`（零依赖，不需要 pip install）。
- [ ] 看第一段输出：**同一个密码注册两次，两个指纹完全不同** —— 这就是盐。
- [ ] 把脚本里的 `pw` 换成你某个密码的**变体**（比如最后一个字母改掉），再跑，看 64 个字符变了几个。
- [ ] 对照实验：用[网页版指纹机](../index.html)算一次同样的内容，和脚本结果比对 —— 应该**一模一样**，
      因为它们用的是同一台「绞肉机」（SHA-256）。

想改代码的话，核心就这几行（也是网站真正干的事）：

```python
import hashlib, secrets

def fingerprint(text):
    return hashlib.sha256(text.encode()).hexdigest()   # 64 个字符的指纹

salt = secrets.token_hex(8)                    # 每个账号一份随机盐
stored = fingerprint(salt + "你的密码")         # 库里存的是这个
# 登录时：fingerprint(salt + 用户输入) == stored  →  放行
```

**提示**：把 `token_hex(8)` 改成 `token_hex(4)`，安全性下降了吗？为什么盐短一点也不要紧，但绝不能「所有用户用同一把固定盐」？

**你会学到**：盐不是密码，它不需要保密 —— 它只需要「每人不同」。

## Lv 3 · 探索（半小时）

**目标**：把这篇讲义的价值兑现在一个真实的人身上。

- [ ] 帮家里一位长辈检查：常用密码是不是「名字拼音 + 生日」？在几个网站重复？
- [ ] 用讲义第 04 节的[估算器](../index.html#slow)算出那个密码「最好情况」的破解时间，告诉对方这个数字（这比讲道理有用得多）。
- [ ] 帮他改成一个好记的**中文短句**，并开启二次验证。
- [ ] 记录改前 / 改后的关键差别：长度、是否重复、有没有第二道门。

**你会学到**：安全建议只有落在具体的人身上才算数。

## 怎么交作业

不写代码、不开 PR 也可以。**去仓库开一个 Issue，标题写「Week02 打卡」**，正文贴上：

1. 你的三句话审计结论（Lv1），或
2. 两条指纹对比 + 变了几格（Lv2，只贴指纹和结构，**别贴密码**），或
3. 长辈密码体检的改前 / 改后差别（Lv3，同样只要结构）

想放代码也可以：`week-02/submissions/<你的GitHub用户名>/`，然后开 PR。

## 完成后你应该能回答

- 为什么网站只能让你「重置密码」，不能「把原密码发给你」？
- 加盐防住了什么，防不住什么？
- 「有绿锁」和「密码存得安全」是同一件事吗？

答不上来就回讲义对应小节再看一眼 —— 这三题就是本期的「毕业考」。

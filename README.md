# 每周一个计算机小知识 · CS Weekly

> 给**爱好者**的计算机常识课：不懂算法没关系，会开机就能读。
> 每周一期：讲清一个「天天在用但说不明白」的东西 + 一个动手小挑战。

🔗 在线讲义：<https://kinghihido.github.io/cs-weekly/>

---

## 定位（重要）

这不是程序员培训，也不打算教你刷题。

- ✅ 讲硬件怎么分工、软件为什么这么设计、电脑坏了怎么判断
- ✅ 每期都有能在浏览器里点的小演示，看完就有体感
- ✅ 挑战以「观察 + 10 行以内代码」为主，零基础能做
- ❌ 不推导复杂数学，不要求手写算法 —— 那些交给 AI

**为什么还值得学？** 因为 AI 能替你写代码，但替不了你「把问题说清楚」。
懂结构、会看资源在哪儿排队、能读懂报错最后一行 —— 这三件事决定你用 AI 的效率。

## 本期速览（Week 02）

| 概念 | 一句话记住 |
| --- | --- |
| 哈希（指纹） | 单向绞肉机：肉进去香肠出来，香肠变不回肉；改一个字，指纹面目全非 |
| 加盐 | 每个账号一把随机盐，让「同一密码」的指纹各不相同，预计算表全部作废 |
| 慢哈希（bcrypt） | 故意算得慢（约 0.25 秒/次），把成本全部转移给攻击者，你却毫无感觉 |
| HTTPS vs 哈希 | 小锁管「路上没被偷听」，哈希管「库里被拖走也还原不了」，两码事 |
| 你该做的 | 不重复 > 够长 > 花哨；二次验证的优先级高于一切 |

**核心句（唯一需要记的一行）**：网站不存你的密码，只存指纹 —— 所以它只能让你重置，不能把原密码发给你。谁能发给你，谁的库就是明文。

本地跑参考实现（零依赖）：

```bash
cd week-02
python salt_demo.py        # 亲眼看：同一密码两次注册，指纹完全不同
python test_salt_demo.py   # 9 个行为测试
```

# Week 01 挑战 · 当一次电脑医生

这周不考算法，考「亲眼看一次」。三级任选，**做完任意一个都算赢**，不需要写超过 10 行代码。

讲义在 [README.md](README.md)，可交互版在仓库根目录的 [`index.html`](../index.html)。

## Lv 1 · 观察（15 分钟 · 零代码）

**目标**：亲眼看见「四种资源在排队」长什么样。

- [ ] 打开任务管理器（Ctrl + Shift + Esc），分别按 **CPU / 内存 / 磁盘** 各排一次序，记下前三名分别是谁。
- [ ] 浏览器连开 15 个标签页，看内存涨了多少 GB。
- [ ] 复制一个 1 GB 以上的大文件到另一个盘，同时看：磁盘是不是冲到 100%？CPU 当时是多少？
- [ ] 用三句话写下结论，例如：「我电脑最吃内存的是微信，占了 2.3 GB。」

**你会学到**：原来卡顿不是玄学，是某一个数字顶到了 100%。

## Lv 2 · 动手（20 分钟 · 10 行代码）

**目标**：让你自己的电脑亲口说出「内存比硬盘快多少倍」。

- [ ] 新建 `memory_vs_disk.py`，把下面这段贴进去，运行。
- [ ] 记下两个秒数，相除得到倍数。
- [ ] 和第 03 节的「速度体感表」对照：你的实测倍数落在哪个区间？为什么和理论不完全一样（缓存、文件系统、硬盘类型都会影响）？

```python
# memory_vs_disk.py —— 亲口问问你的电脑：内存和硬盘差多少倍？
import time

N = 1_000_000
t0 = time.time(); data = [0] * N; t1 = time.time()   # ① 写内存
print(f"写内存 100 万个数：{t1-t0:.3f} 秒")

t0 = time.time()
with open("test.txt", "w") as f:                      # ② 写硬盘
    for i in range(N): f.write(f"{i}\n")
t1 = time.time()
print(f"写硬盘 100 万行：{t1-t0:.3f} 秒")
```

**提示**：把 `N` 改成 100 万 → 500 万，倍数会怎么变？为什么？（想一想：内存操作是「一次性分配」，硬盘是「一行一行写」。）

**你会学到**：数字感。以后看到「内存比硬盘快百倍」不再是背下来的句子，是你测出来的。

## Lv 3 · 探索（半小时）

**目标**：认领你自己的硬件。

- [ ] 查清三件事：CPU 型号 / 内存容量 / 硬盘是固态还是机械。
      （Windows：设置 → 系统 → 关于；内存和硬盘在任务管理器「性能」页也能看到）
- [ ] 对照讲义第 2 节的分工表，写一句话判断：**你这台机器日常的瓶颈最可能是哪一环？依据是什么？**
- [ ] 可选：搜「你的 CPU 型号 + 天梯图」，看看它排在哪，值不值得换。

**你会学到**：判断该不该花钱升级，而不是被广告牵着走。

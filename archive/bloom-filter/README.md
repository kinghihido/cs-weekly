# 归档 · 布隆过滤器（Bloom Filter）

这是第 01 期最初的版本：用概率型数据结构讲"省内存"，含误判率推导、双哈希技巧、工程参数表。

**为什么归档**：面向的是有算法基础的读者，数学推导 + 手写实现的门槛对爱好者偏高。现在的第 01 期改成了硬件与开发逻辑入门（见 [week-01](../../week-01/README.md)）。

内容本身没有错，喜欢硬核的可以直接看：

- `bloom.py` —— 零依赖实现，`bytearray` 按位存储，blake2b 双哈希，带实时误判率估算与元素数反推
- `test_bloom.py` —— 9 项测试（零假阴性、实测误判率与理论同量级、内存校验等）

```bash
python bloom.py        # 演示：内存占用、实测误判率、反推元素数
python test_bloom.py   # 9 项测试
```

**三分钟版结论**：p ≈ (1−e^(−kn/m))^k，最优 k ≈ 0.693·m/n，每元素 m/n = −ln(p)/(ln2)²。
1% 误判只需 9.6 bit/元素；位只会 0→1，所以永不漏判，代价是不能删除。
